description : Data Preprocessing Pipeline (ETL)

Objective:
Create a pipeline to handle Extract, Transform, Load (ETL) operations using Pandas and Scikit-learn.

Description:
This task involved building a robust data preprocessing pipeline that:

    Loads raw data into a structured format

    Handles missing values in both numerical and categorical columns

    Applies standard scaling to numerical features

    Encodes categorical features using one-hot encoding

    Outputs the transformed data ready for machine learning models

The pipeline was implemented using ColumnTransformer and Pipeline objects in Scikit-learn for modular and reusable design.
